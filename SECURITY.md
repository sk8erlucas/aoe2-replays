# Security

**Please don't report vulnerabilities in public issues.**

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it and its impact. We'll answer as soon as we can and credit you in the fix if you want.

In scope: the web app (aoe2replays.sitemaster.com.ar), the replay parser service, and anything in this repository (uploads, private replay links and management tokens, rate limits, the match download from Microsoft's service).
