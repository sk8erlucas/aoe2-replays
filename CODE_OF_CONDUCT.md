# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, no harassment or discrimination of any kind. This applies to issues, pull requests, discussions and any other project space.

Report unacceptable behavior privately to the maintainers through GitHub (Security → Report a vulnerability works for private contact too). Maintainers may remove comments or contributions and block people who don't follow this code.

---

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/): respeto, buena fe y cero acoso o discriminación, en issues, pull requests y cualquier espacio del proyecto.
